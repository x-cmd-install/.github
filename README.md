# .github

Org-level defaults for **x-cmd-install**.

`profile/README.md` is what GitHub renders on the organization's landing page:
<https://github.com/x-cmd-install>. It covers what the per-software snapshots are, how
they're collected, and the best place to send ideas and fixes.

This repository isn't one of the per-software snapshot repositories. For those, and for
the aggregated data, see
[x-cmd-install-stat](https://github.com/x-cmd-install/x-cmd-install-stat).
