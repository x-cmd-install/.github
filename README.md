# .github

Org-level defaults for **x-cmd-install**.

`profile/README.md` is what GitHub renders on the organization's public landing page:
<https://github.com/x-cmd-install>. It explains where the per-software snapshots come
from, and where to go instead of opening an issue or PR here.

This repository is not one of the per-software snapshot repositories. For those, and for
the aggregated data, see
[x-cmd-install/x-cmd-install-stat](https://github.com/x-cmd-install/x-cmd-install-stat).
